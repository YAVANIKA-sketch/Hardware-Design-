# 🚀 Journey to Space Systems: Electronics Hardware Design

Welcome to my learning log! This repository documents my journey from foundational electronics to designing reliable, mission-critical hardware for space systems (CubeSats, avionics, and payload subsystems). 

## 🎯 The Mission
To bridge the gap between software/general engineering and rigorous electronics hardware design tailored for the unique challenges of the space environment (thermal, vacuum, radiation, and vibration).

## 🛠️ Tech Stack & Tools
* **Schematic & PCB Design:** KiCad / Altium Designer
* **Simulation:** LTspice / Ngspice
* **Firmware/Testing:** C/C++, Python, STM32, ESP32, FPGAs
* **Lab Equipment:** Oscilloscope, Multimeter, Logic Analyzer

## 🗺️ Roadmap / Learning Phases
- [ ] **Phase 1: Fundamentals** — Analog/digital circuit design, passive/active components, and soldering.
- [ ] **Phase 2: Schematic Capture & PCB Layout** — Multi-layer routing, impedance control, grounding, and EMI/EMC best practices.
- [ ] **Phase 3: Power Systems (EPS)** — Solar panel power harvesting, DC-DC converters, battery management (BMS), and power distribution units.
- [ ] **Phase 4: Avionics & Data Handling** — Microcontrollers, sensors, CAN bus / SPI / I2C communication protocols, and flight computer architecture.
- [ ] **Phase 5: Space-Grade Considerations** — Radiation effects (SEUs, TID), thermal dissipation, and component derating.
